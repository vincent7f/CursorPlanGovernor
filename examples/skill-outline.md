# plan-governance Skill Outline

## Purpose
Guide Cursor to produce small, reviewable, versioned plan trees instead of ephemeral chat-only plans.

## Guidance
- Prefer 2-4 levels of decomposition.
- Every work item should have a clear title and acceptance criteria.
- Avoid speculative subtasks unless risk justifies them.
- Replan by creating a new revision, never by overwriting the previous one.
- Link actual implementation evidence back to work items.
